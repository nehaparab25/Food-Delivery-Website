# Foodie Website

A responsive food delivery landing page with a dynamic menu, cart interactions, and a reviews slider.

## Features

- Responsive navbar with mobile menu toggle
- Menu cards rendered from products.json
- Add to cart with quantity controls and total updates
- Sliding cart panel
- Reviews slider using Swiper

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Swiper.js (CDN)
- Font Awesome (CDN)

## Project Structure

- index.html - Page layout and sections
- style.css - Styling, layout, and responsive rules
- main.js - Menu rendering, cart logic, and slider setup
- products.json - Menu data source
- images/ - Icons and product images

## Run Locally

1. Open index.html in a browser.
2. Or use a local server for best results (e.g., VS Code Live Server).

## Notes

- Menu items are loaded from products.json and rendered into the menu section.
- Cart totals update based on quantities and remove an item when its quantity goes below 1.
